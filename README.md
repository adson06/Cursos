📚 Repositório de Estudos – Cursos de Tecnologia
Este repositório reúne materiais, exercícios e projetos desenvolvidos durante diferentes cursos e trilhas de aprendizado na área de tecnologia.
O objetivo é centralizar conteúdos estudados ao longo da minha formação em Ciência da Computação, incluindo práticas, exemplos de código e materiais utilizados durante os cursos.

🚀 Tecnologias e Ferramentas Estudadas
Os conteúdos deste repositório envolvem estudos e práticas com diferentes tecnologias, como:
 Java
 Python
 SQL
 Power BI
 Excel
 Git e GitHub
 Metodologias Ágeis (Scrum)
 

Novos conteúdos serão adicionados conforme avanço nos estudos.
📂 Estrutura do Repositório
Cada pasta representa um curso ou trilha de aprendizado:
Cursos/
│
├── POWER-BI
│   └── Dashboards e exercícios de análise de dados
│
├── TIC-em-trilhas-Git
│   └── Estudos sobre controle de versão com Git e GitHub
│
├── TIC-em-trilhas-Scrum
│   └── Conceitos e práticas da metodologia ágil Scrum
│
└── materiais-de-apoio
    └── Conteúdos complementares utilizados nos cursos
Novas pastas serão adicionadas conforme novos cursos forem concluídos.

🎯 Objetivo do Repositório
Organizar conteúdos estudados durante cursos
Registrar minha evolução técnica
Armazenar exercícios e práticas de programação
Servir como material de consulta futura
